# THE ONE LANE (2026-07-09) — learned physics, from experience only

Written at the user's request after the legal_search verdict: one tangible,
understandable, permissible thing to move forward with. This page is the whole
plan. If a task doesn't fit on this page, it's not this lane.

## What you are training (one sentence)

**You are training the game's physics and the game's win condition, from your
own play experience, and winning by imagining pours before making them.**

That's it. Two models, one loop. No hand-coded rules enter the agent.

## The permissibility test (apply to every future idea, yours or an agent's)

Ask of any bit of knowledge the agent uses: **"Where did this come from?"**

- From the environment's responses to our own actions → **legal**.
- From a human — routes, win conditions, physics rules, game source facts —
  coded into the agent → **specialist lane at best, cheat at worst. Not this lane.**

This single question replaces the whole quarantine debate going forward.
The hand-coded sim3d simulator fails this test (physics written by hand,
calibrated from game source). It may remain as an offline *baseline to compare
against*, but nothing it computes feeds the agent in this lane.

## The loop

```
act in the game  →  record what happened  →  train models to predict it
      ↑                                                    ↓
env grades the pours  ←  pour the best few for real  ←  imagine + rank
```

Every artifact is inspectable: datasets on disk, checkpoints, and side-by-side
PNGs of *imagined* vs *real* settled boards. When it fails you can see the
failure in pixels.

## Stages (each has one deliverable and one pre-registered exit test)

**Stage 0 — the diary (collector).** Play SP80 from level 0, fresh runs only
(from-zero ruling). Exploratory pours. Record per pour:
`(board_before, action, settled_board, env_verdict, level)`.
*Deliverable:* `transitions_v1.pt` + a contact sheet PNG.
*Exit:* ≥ 2,000 env-graded pours, episode-keyed train/val split, t0-five untouched.

**Stage 1 — learned physics (dynamics model).** Train
`(board_before, action) → settled_board`. This is the settle_predictor lineage
(the honest one), retrained on Stage-0 data. It **replaces** the hand sim.
*Deliverable:* checkpoint + 20 side-by-side imagined/real renders.
*Exit:* held-out settled-board pixel agreement ≥ 0.90 on val episodes;
renders eyeballed and archived.
(Not the banned static-board outcome CNN — this is action-conditioned dynamics,
exactly the direction STAGE_PT pointed to.)

**Stage 2 — learned win sense (probe).** Train `settled_board → win/fail` on
env verdicts only. The win condition is *learned from grades*, never coded.
*Deliverable:* checkpoint. *Exit:* held-out AUC ≥ 0.95 (v52 already showed this
bar is reachable).

**Stage 3 — close the loop (solve + grow).** Propose arrangements (random +
CEM), imagine each with Stage 1, rank with Stage 2, pour top-K for real, env
grades, append results to the diary, retrain. *Exit metric — the only headline
number this lane reports:* **levels won from a fresh run, agent alone.**
Current honest baseline to beat: 2.

## How walls are handled in this lane

When the model is wrong somewhere (e.g. multi-source L2 fills), the move is:
**collect more transitions where it is wrong, retrain, re-render.** Never
hand-patch physics, never read game source into the agent. Every wall becomes
a data problem — which is training, which is the point.

## Standing guardrails (unchanged)

honesty_audit leads every report; evidence contract holds; t0-five untouched;
no imitation/route lineage; `_invalid/` never imported; gates pre-registered
before runs, results reported against them win or lose.
